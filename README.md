# 📚 LetterB Project

## Overview

LetterB is a book-themed e-commerce website inspired by platforms like [Litera.ro](https://www.litera.ro/). The application allows users to browse books, view information about authors, add books to a shopping cart, log in, and create an account.

The project was built using PHP for the backend, along with HTML, CSS, and JavaScript for the frontend. It represents a full-stack web app that simulates the core features of an online bookstore.


## What I Learned

Throughout the development of this project, I learned and practiced a variety of web development skills and technologies, including:
- PHP for backend logic and server-side scripting
- MySQL for database management of users, books, and orders
- HTML & CSS for building and styling web pages
- JavaScript for adding interactivity (e.g., shopping cart functionality)
- Connecting frontend and backend for full functionality
- Managing user sessions for login and registration
